## 领域已知未知清单模板

开工时逐条过:已答 = KK;未答 = KU,入覆盖表;答不出"该问什么" = 先跑 blindspot pass。

### AR 新景点

- 识别目标是什么?(真实建筑照 / 平面卡 / 磁贴——触发约束完全不同)
- 美术方向参照物有吗?(没有 = UU-b 风险,先 blindspot pass + 找对标)
- 文化正确性红线?(宗教场所 / 神像 / 民俗动作——默认 C 档)
- 真机约束我知道哪些?(光照 / 角度 / 抖动 / 机型碎片化)
- AR 收束态产出什么?(打卡 token 铁律)
- 验证器和真机会不会分叉?(「验证决策」必须显式设计,scene_verify 之鉴)

### Blender / 3D 动画

- 全部物高 / 比例在建模前钉死了吗?(I2:否则被生成工具随机决定)
- 道具清单 + turnaround 三视图有吗?(动作必须对得上道具,不许空手比划)
- 骨骼命名 / 单位 / 朝向 / 目标引擎限制(GLB≤2M、无 meshopt)枚举过吗?
- 生成工具的版本 / 档位参数枚举过吗?(Tripo 之鉴——省略的参数都是地雷)
- 动画验收方式定了吗?(多帧 GIF / kimi 直读视频;单帧姿势 ≠ 动画)

### 磁贴 / 文创卡

- 主角 1 + 陪衬 2-3 + 特效,层数 5-8 封顶(相关性≠复刻)
- 画面饱满度 / 3D 感 / 多角色在设计端前置了吗?(R3"一般"病根)
- 预渲染视频 vs 实时 3D 的选型是否已由项目阶段合同冻结并验证?
- 抠背景 alpha 合成到实时相机?(全屏不透明视频 = 矩形廉价感根因)
