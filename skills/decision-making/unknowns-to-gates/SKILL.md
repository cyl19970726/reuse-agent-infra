# unknowns-to-gates:未知→决策→执行→固化的全链路防错

> 地图不是疆域。地图 = prompt / skill / context / 设计件;疆域 = 代码库、真机、生成模型的真实行为、用户脑中的标准。
> 两者的差 = **未知**。本 skill 管的是:未知如何变成错误,以及在每个环节怎么拦。

## 0. 公理

1. **决策不会等你**。你不做,它也会被做出——被默认值、生成模型的随机性、"行业最佳实践"的猜测、或"无人决定"(= 错的决定)代做。
2. **错误 = 重要决策在错误的象限里被低质量决策者做出,且无人察觉。**
3. **双边性**:开工时用户和 agent 各持一张对方没有的地图。用户的"显然"对 agent 是盲区,反之亦然。大量事故的根源不在任何一方脑内,在**两张地图的差集**里。疆域还包括 **agent 自身的行为倾向**(默认假设 / 常见失误模式)——顶尖使用者与"代码库 + 模型行为"双同步,给任务时会预判 agent 会在哪猜、猜向哪边。

## 1. 四象限错误发生学

每个象限孕育一种特定错误,症状、成本、暴露时机都不同:

| 象限 | 定义 | 错误产生机制 | 暴露时机 | 单价 |
|---|---|---|---|---|
| **KK 已知的已知** | prompt 里写了的 | **传递失真**(说得歧义/理解偏);**过度指定陷阱**(钉太死,该转弯也死守) | 早,review 可抓 | 低 |
| **KU 已知的未知** | 知道自己没想清的 | **明知未定仍开工** → 被默认值/猜测代做 | 中游 | 中(最冤,完全可预见) |
| **UK 未知的已知** | 对一方显然到不会写、对另一方纯盲区 | **猜测→看到才爆**:按最佳实践猜,对方看到成品瞬间识别违背 | 首次看到产出那一刻 | 高(每个吃一整轮) |
| **UU 未知的未知** | 没人考虑过 | 两种子型:**(a) 碰撞型**——执行深处炸,一次一个;**(b) 静默封顶型**——永不报错,悄悄封死质量上限("不知道好能有多好") | (a) 执行深处 (b) **永不** | 最高 |

真实事故对照(详见 [cases.md](cases.md)):空手倒茶 / 贴边当画布 / 复刻17层 = UK;Tripo 降档 = 视野内节点的选项面是 UU;scene_verify 与真机分叉 = UU-a;"土 vs 高级"分不清 = UU-b;桌高 churn = 象限倒退(§2)。

两个推论:
- **UK 全部是双边差集错误**,治法全是"传递"类:早出原型让对方反应、interview、参照物——不是"想得更仔细"。
- **UU-b 静默封顶最危险**:其他错误都有报警信号(碰撞/发怒/返工),它没有。唯一解是外部输入:行业结晶、对标参照、"教我这个领域"。

## 2. 迁移动力学 + 症状路由(总图)

象限不是静态标签。知识在象限间迁移,且迁移会**倒退**:

```
     显影            深挖(预算分配)        固化
UU ─────────→ KU ─────────→ KK ─────────→ 闸(不可倒退的 KK)
 ↑                            │
 └────────── 倒退 ←───────────┘
   (台账里"知道",执行时行为上等于不知道)
```

**"知道"不是二值的**:写在台账 = 名义 known,执行时 functionally unknown。桌高 churn 事故完整走了一圈:UU → 撞 → 入台账变 KK → 执行时倒退 → 又 churn 6 次。

**症状 → 防线路由表**(本 skill 四个文件即四个迁移算子):

| 症状 | 病灶 | 去哪 |
|---|---|---|
| 没做过的复杂任务要开工 | UU 未显影 | 先 [techniques.md](techniques.md) 前置技法钓一轮 → [closure.md](closure.md) 建决策覆盖表,**无表不动工** |
| 用户说"你看着办" / 我预演不出用户看到成品的反应 | UK 差集 | [techniques.md](techniques.md)(多方向原型 / interview / 参照物) |
| 同一步反复返工重抽 / 打算"就用默认值" / 解释它时会心虚 | 节点在视野内但被浅探 | [exploration.md](exploration.md)(先判该不该深挖,再挖) |
| 撞过的坑又复发 | 象限倒退 | §6 固化条款 |
| 成品"能用但土" / 不知道好能有多好 | UU-b 静默封顶 | [techniques.md](techniques.md) blindspot pass + 外部参照 |
| 复盘"为什么一直失败" | 闭包残缺 | [closure.md](closure.md) 三来源重建 + 盲集回溯测试 |

## 3. 授权三档(强制协议)

定档公式:**象限 × 猜错单价**。同一象限的未知,在对话里猜错 = 一轮问答(便宜,可以猜);在渲染管线里猜错 = 一整轮返工(贵,必须问)——**档位跟着单价走**。

| 档 | 定义 | 行为 |
|---|---|---|
| **A** | 真 KK / 机械选择 | agent 自己定,不必说 |
| **B** | 双方都 unknown 但方差低、可逆 | agent 自己定,**必须**记 deviations log |
| **C** | agent unknown 而用户 known;或答案改变架构 / 美术方向 / 文化正确性 / 用户可见行为;或猜错单价 ≥ 一轮返工 | **必须停下问,猜 = 违规**(可证伪不变量) |

默认档位表(用户没声明时):美术方向 / 构图 / 文化动作正确性 / 用户可见行为 = **C**;实现路线 / 库内选择 = **B**;命名 / 格式 / 机械重构 = **A**。

C 档提问纪律:攒批提问、一次一问、优先问"答案会改变架构/方向"的、每问附一句为什么重要;禁止 20 连问轰炸。问出的答案**直接入覆盖表**,不许只留在对话里(否则象限倒退)。

## 4. 任务开工协议

**用户侧 prompt 模板(三段)**:
1. **起点声明**:我知道什么 / 不知道什么 / 哪块是新领域 / 我见过什么好的
2. **参照物**:源码 / 对标视频 / 图 > 文字描述(⚠️ 相关性≠复刻:参照给的是语汇与氛围,不是 1:1 搬)
3. **授权声明**:本次哪些决策升 C / 降 A

**agent 侧第一动作**(收到任务、开干之前):先做**目标回声**(techniques.md T0:复述目标/成功标准/验收者,展开所有指代词);然后命中任一信号 → 走 techniques.md 钓一轮,**不许直接动工**:
- 新领域 / 新管线 / 没做过的任务类
- 用户说"你看着办 / 随便 / 都行"
- 同类任务上次返工 ≥2 轮
- 我无法在心里预演出用户看到成品时的反应
- 复杂多阶段任务 → 直接 closure.md,无表不动工

**进展感警戒**:"模型出来了 / 脚本跑通了 / 机检绿了" ≠ 未知清零。执行者的进展感会掩盖闭包债。
**沉默≠认可**:报捷后用户没纠 ≠ 验收通过——纠偏常成批延迟爆发(文创 AR 案例 实测:报捷被打脸约 1/4~1/3,且攒成"集中"否定反馈)。更细的结构:**后台工程报捷零打脸(用户根本没看,沉默=零采样);真机/真图亮相的那一刻才是唯一验收采样点**。只有用户对**具体产物**的明确肯定才算 KK;把"没被骂"当方向确认,就是在拿 UK 当 KK 用。

**换 session 执行纪律**:计划满意后,**新开 session 执行,只把 artifact(spec / 原型 / 覆盖表 / deviations log)传进 prompt**。这不只省 context,更是一道可证伪闸:**换个新 session,这个决策还存在吗?**——不存在 = 它只活在对话里 = 已处于象限倒退。凡是"新 session 带不走"的共识,当场落成 artifact。

## 5. 执行中 tripwire(撞到未知的现场协议)

撞到未知 → 先判档(§3):
- **C 档 → 停下问**,不许猜。特别警惕:"看起来只有一种合理做法"是 C 档未知最常见的伪装。
- **B 档 → 选保守方案 + 记 deviations log + 继续**
- **A 档 → 直接过**

deviations log(implementation-notes.md)每条格式:遇到什么 / 选了什么 / 为什么保守 / 属哪个象限。

**升级判据**(什么时候不该"绕过去"而该"回头改方案"):发现推翻的是**计划的前提**而非细节 → 停,回 §4 重新开工,不在错误前提上堆工作量。判别句:"如果开工前就知道这个,计划还会长这样吗?"——答否即升级。

## 6. 事后固化(防象限倒退)

> 本节吸收自 operationalize-insights-as-gates:**洞见停在台账 = 会复发。"引用洞见" ≠ "应用洞见"。**
> 实证:insight-ledger 早已盲中"全部物高必须建模前钉死"(I2),生产里桌高仍 churn 6 次——不是不知道,是没操作化成闸。

每次交付后强制跑一遍**未知复盘**(5 分钟级):
1. 本次最贵的未知是哪个?归象限。
2. techniques.md 里哪个技法本可在它变贵之前钓到它?
3. 沉淀路由:
   - 一次性教训 → 落成**强制闸**(checklist / 自动校验 / 不过不许进下一步),不是只记一笔
   - 领域知识 → 对应领域 skill 的活文档
   - 决策类 → closure.md 覆盖表补行(**修表优先于修实例**)
   - 事故本身 → cases.md 归档
4. 可选 **quiz**:让用户带上下文读改动报告 + 答测验,满分才 merge(治用户对成品的理解债)。

Why 必须是闸:过程类决策(先规划还是先动手、何时验收)是系统性盲区,靠"记得"必然倒退;只有闸不依赖任何人的记忆。

## 7. Subagent 条款

- fan-out 之前,先对**自己**跑一遍 blindspot pass:这个任务里我的未知是什么?
- 把已钓出的 KU / 已定决策显式写进 worker prompt——**worker 的 UK = 我的 known**,我对 worker 负有与"用户对我"同构的传递义务;否则 worker 把每个坑重撞一遍。
- 在 worker prompt 里写明:撞到 C 档未知 → 上报,不许猜。
