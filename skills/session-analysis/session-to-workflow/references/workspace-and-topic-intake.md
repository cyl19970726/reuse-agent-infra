# 工作区、选题与持续沟通

适用于多账号或多业务空间的重建；不是额外生产阶段。先确认业务身份与工作区边界，沿用当前用户已确认的隔离单位。同一创作者身份的多个平台通常作为该身份的发布渠道，共用定位与内容生产，分别记录包装和回执；不同身份或独立业务空间分区，内容跨区复用时明确导入。不得把历史中已被纠正的“每个平台一个工作区”当作通用规则。

## 恢复上下文属于谁

每区分别恢复账号身份、长期目的、目标读者、内容范围，以及选题、产物版本、意见接受、发布授权与反馈。区分已确认、当前建议、未知、历史记录；一个账号的已确认读者不能自动填进新账号。长期定位在区内跨选题复用，单篇说明继承了什么、这次回答什么问题、产出什么载体。

按实际逐平台回执核已有内容，旧准备文案与品牌摘要不能覆盖真实身份和状态。没核清归属的资料单独保留；审核中、预约与已发布分别记录。历史记录不证明当前仍公开或当前登录正确。

共用 skill 和模板不等于共用账号决定。跨区内容显式导入源版本、目标和用途；源区记录保留，目标区独立审阅和发布。只做界面筛选不构成数据隔离，资产读取、搜索、意见写入、父版本及回执也需校验范围。若只实现本机数据分区，不声称多用户鉴权。

## 选题入口不决定最终载体

用户明确给题可直接进入已有研究流程。RSS、热点、评论等只增加线索来源；Agent 对候选说明本区读者价值、新增内容、已有覆盖、依据与投入，再按用户选择或已授权规则推进。研究可以交素材、报告、图文或视频，不把全部候选机械送进完整视频流程。

选题清单要包括在做、已有成果、已发布及暂缓原因。重复、更新和新角度需对照本区库存说明理由；没有读过库存就不称已去重。未来自动化设想不自动授权排程、批量生产或外发。

## 把沟通放在需要判断的资产上

同一报告集中呈现：账号定位；研究后的单篇定位与关键图文；所选载体的设计；必要的低成本样片；实际平台交付包；发布反馈。每份包说明看什么、决定什么、建议与理由、接受后的动作及返工位置，不把包变成额外审批阶段。

所有关键资产可审；用户参与下限由真实方向取舍、新偏好、商业承诺、身份冲突和授权边界决定。常规修复由Agent闭环，已授权代理继续在范围内接受。价格依赖产品时到销售包再集中决定，不前置阻塞研究。

## 有界验证

分别验证账号切换与读写隔离、显式导入后的独立决定、用户能否恢复全貌、选题是否值得投入、作品质量和发布结果。先用实际历史验证库存与上下文，再固定候选线索和账号库存，让Agent独立选择、与用户判断对照；自动生产的范围随验证结果调整。界面可用、制作链可跑和选题策略有效分别报告。
